# IDE_for_platform

Платформа с встроенной IDE и пользовательским интерфейсом. Содержит ядро (Core), IDE для разработчиков и пользовательский режим (User). Также используется модуль-анализатор (Anlizator).

## Описание

Проект представляет собой кроссплатформенное приложение на PyQt5 с выбором режима запуска:

- **Developer mode (IDE)** — режим разработки/редактирования модулей (запускается через `IDE.main.run_ide`).
- **User mode** — пользовательский интерфейс для работы с модулями платформы (класс `User.main.myWindow`).

Точка входа: `main.py`. При запуске открывается окно выбора режима, после чего запускается соответствующий интерфейс.

## Предварительные требования

1. **Распаковать Anlizator.7z**
   - Распаковать архив `Anlizator.7z` и перенести файл `temp.seq` и каталог `analiz` из `Analizator/analyzer/` в корень диска `C:\`.
   (См. исходную инструкцию в README.)

2. **Python 3.x**

## Установка зависимостей

Файл `requirements.txt` в корне сохранён в кодировке UTF-16 LE (BOM). Его необходимо предварительно сконвертировать перед установкой.

### Вариант 1. Конвертация и установка (Linux/macOS)

```bash
# Конвертация в UTF-8
iconv -f UTF-16LE -t UTF-8 requirements.txt > requirements_utf8.txt

# Создание и активация виртуального окружения
python -m venv .venv
source .venv/bin/activate

# Установка зависимостей
pip install -r requirements_utf8.txt
```

### Вариант 2. Windows (PowerShell)

```powershell
Get-Content requirements.txt | Set-Content -Encoding UTF8 requirements_utf8.txt
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements_utf8.txt
```

> Также в подпапках (`IDE/requirements.txt`, `User/requirements.txt`) есть свои списки зависимостей — при необходимости можно использовать их отдельно.

## Запуск

После установки зависимостей и распаковки анализатора:

```bash
python main.py
```

Откроется окно выбора режима:

- **Developer mode** — запускает IDE (`IDE/main.py`)
- **User mode** — запускает пользовательский интерфейс (`User/main.py`)

## Кратко о ключевых модулях

- `main.py` — главное окно выбора режимов, создаёт `CoreController` и запускает выбранный режим.
- `Core/CoreController.py` — контроллер ядра платформы.
- `IDE/main.py` — интерфейс разработчика.
- `User/main.py` — пользовательский интерфейс.

## Примечания

- Корневой `requirements.txt` содержит большой набор зависимостей (морфология, NLP, текстовые утилиты, PyQt5 и др.).
- Для работы анализатора обязательно требуется наличие `temp.seq` и каталога `analiz` в корне `C:\`.
- Файлы `.venv/`, `venv/`, `__pycache__/` игнорируются в `.gitignore`.
