Для запуска платформы необходимо:
1 - Распаковать архив “Analizator.7z” и перенсти файл “temp.seq” и каталог “analiz”, находящиеся по пути "Analizator\analyzer" в корень диска C.
2 - Установить необходимые библиотеки из файла “requirements.txt”, находящийся в корневом каталоге платформы.
3 - Запустить платформу, используя команду "python .\main.py".
