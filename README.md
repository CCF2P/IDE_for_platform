Для запуска платформы необходимо:
1 - Распокавать архив “Analizator.7z” и перенсти файл “temp.seq” и каталог “analiz” в корень диска C.
2 - Создать виртуальное окружение для языка Python.
3 - Установить необходимые библиотеки из файла “requirements.txt”, находящийся в корневом каталоге платформы.
4 - Запустить платформу, используя команду "python .\main.py"
